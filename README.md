# Pasos

1.- Crear carpeta biblioteca.
2.- Abrir carpeta.
3.- Crear entorno virtual.
4.- Activar entorno virtual.
5.- Instalar biblioteca de Flask.
6.- Crear archivo requirements.txt.
7.- Crear estructura de carpetas y archivos.
8.- Crear archivo server.py con sus funciones.
9.- Crear archivos HTML y sus contenidos. Recuerda solo crear el contenido que va entre <div>...</div>.
10.- Crear archivo layout.html con su navbar de Bootstrap y su block content.
11.- Agregar la herencia a cada página y su block content.
12.- Enlazar el navbar con cada página.
13.- Modificar archivo index.html con su contenido.
14.- Modificar archivo servicios.html con su contenido.
15.- Modificar archivo catalogo.html con su contenido.
16.- Modificar archivo contacto.html con su contenido.
17.- Crear el repositorio en GitHub.
18.- Modificar el archivo README.md con su contenido.
19.- Crear el repositorio en GitHub.
20.- Subir el repositorio a GitHub.
21.- Entregar el URL del repositorio a la tarea.
